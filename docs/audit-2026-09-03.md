# Аудит проекта «Этикетка» — 03.09.2026

Полный аудит кода, автоматизации, контента и фактической работы сайта для читателя.
Проверено: свежая сборка (`npm run build`), обход всех 469 HTML в `dist/`, живой сайт
etiketka-media.ru, прогон Playwright (десктоп 1366px и мобильный 390px), история
GitHub Actions, Routines на claude.ai/code, статистика по 116 статьям.

## Резюме

Сайт технически исправен: сборка проходит за 43 секунды, битых внутренних ссылок и
картинок нет, все 116 статей с hero и WebP, поиск, калькулятор, календарь и тест
работают. Дизайн цельный и на мобильном не ломается (горизонтального скролла нет).

Главные проблемы лежат не в коде, а в «жизни» проекта:

1. **Конвейер контента стоит.** Последняя статья вышла 06.07.2026, 59 дней назад.
   Очередь черновиков пуста, Routine «Этикетка — черновики» 31.08 отработала
   «успешно», потратила около 11 $ и не оставила ни одного черновика.
2. **Флагманская тема устарела.** Дедлайн ТС ПИоТ 01.07.2026 прошёл два месяца
   назад, а 59 статей, pillar, тест, лендинг и календарь всё ещё написаны в будущем
   времени («до 1 июля успейте», «остаются недели», «0 дней»).
3. **Аналитика не работает.** `articles.json` — заглушка от 20.05.2026 с нулями,
   дашборд показывает пустоту, GSC/Метрика/Вебмастер ни разу не подтянулись.
4. **Репозиторий раздувается.** 178 МБ данных Wordstat, коммиты дважды в день,
   каждый роняет встроенную сборку Pages (Jekyll) и шлёт письмо об ошибке.

### К4. Репозиторий раздут данными Wordstat, деплой-конвейер шумит

- `src/data/wordstat/discoveries/` — 171 МБ, из них `kontur/` — 51 файл-снапшот,
  добавляется по 2 в день (`wordstat-kontur.yml`, cron `17 12` и `22 13`). Pack-файл
  репозитория уже 139 МБ, сборка тянет всё это в checkout каждого воркфлоу.
- Каждый бот-коммит запускает встроенный «pages build and deployment» (Jekyll), он
  падает на шаге «Build with Jekyll» — 2 красных прогона в день с 29.08
  (например, run 33782503145). Это значит, что в настройках Pages источник стоит
  «Deploy from a branch», а не «GitHub Actions» — нужно переключить, тогда Jekyll
  перестанет запускаться.
- Пуши от `github-actions[bot]` по правилам GitHub не запускают другие воркфлоу, поэтому
  `deploy-gh-pages.yml` срабатывает только по cron 05:00 UTC. Опубликованная в 04:00
  UTC статья появится на сайте через час, а выпущенная в 08/12/16 UTC — только на
  следующее утро. Не ошибка, но стоит зафиксировать в `docs/autopilot.md`.

Что делать: хранить в репозитории только последние N снапшотов (или один агрегат) и
чистить старые в том же воркфлоу; убрать второй cron (второй прогон в 13:22 даёт
дубль-коммит «wordstat-kontur: refresh» в тот же день); переключить Pages на источник
«GitHub Actions».

  креативы через `ord.yml`, либо не показывать офферы без erid (как уже сделано в
  `KonturLeadForm`).
- **Форма подписки мертва.** Попап на главной (`PopupBanner.tsx`) ведёт на
