# /auto-audit — недельный аудит

Суточный проход следит за выработкой. Этот — за тем, что выработка не
деградирует. Раз в неделю, отдельной рутиной.

Автономный контур ломается тихо: гейты пропускают всё подряд, генератор тем
крутит вариации одного кластера, граф ссылок зарастает сиротами. Ни один из
этих отказов не роняет прогон — поэтому их ищут расписанием, а не по симптому.

## 1. Дубли в корпусе

```bash
node autopilot/scripts/dedupe.mjs scan
```

Пары с вердиктом `merge` — это два материала, конкурирующих за один запрос.
По каждой: слабейшую статью (меньше входящих ссылок, ниже балл гейтов) ставь
в очередь рерайта с причиной «развести с <slug>», в сильную добавь ссылку на
неё. Склеивать в одну статью и удалять вторую **нельзя** — удаление URL это
решение принимающего проекта, не автопилота.

## 2. Граф ссылок

```bash
node autopilot/scripts/interlink.mjs graph
node autopilot/scripts/interlink.mjs apply
```

Смотри на три числа: среднее исходящих (норма 3–8), количество сирот
(входящих < 2), количество тупиков.

Если сирот больше 15% корпуса и `apply` их не разбирает — значит, движку не
за что зацепиться: у статей-сирот нет якорей, встречающихся в других текстах.
Такие темы идут в очередь рерайта с причиной «нет входящих»: переписывать
нужно **доноров**, добавляя абзац, где сирота уместна по смыслу.

## 3. Карантин

```bash
node autopilot/scripts/pipeline.mjs report
```

Разбери каждую тему в карантине. Три исхода, других нет:

- **Тема годная, текст не вышел** — вернуть в бэклог руками, сняв счётчик
  неудач: `node autopilot/scripts/backlog.mjs drop --slug <s> --reason "перезапуск"`, затем
  следующий `refill` сгенерирует её заново под другим углом.
- **Тема плохая** — оставить в карантине, дополнив `autopilot/data/seeds.json`, чтобы
  генератор больше не приносил такой угол.
- **Гейт слишком строг** — правь `autopilot/config/autopilot.config.json`. Отдельным
  осознанным решением, с записью в CHANGELOG, а не «чтобы прошло».

Больше 10 тем в карантине — это отказ контура, а не список задач. Разбирайся с
причиной, а не с элементами списка.

## 4. Темп месяца

```bash
node autopilot/scripts/state.mjs month
```

Сверь `done` с `expectedByToday`. Долг больше 20% месячной нормы означает, что
дневная норма не выбирается системно. Причины по частоте:

1. Гейты заворачивают больше трети написанного — смотри, какая проверка чаще
   всего в блокерах, и чини инструкцию `/auto-write`, а не порог.
2. Бэклог пустеет — `node autopilot/scripts/backlog.mjs stats`, добавь сущности в seeds.
3. Слоты заняты зависшими нарядами — `state.mjs get` покажет `inFlight`,
   который не двигается сутками.

## 5. Здоровье данных

```bash
npm test
node autopilot/scripts/interlink.mjs apply --dry
```

Тесты держат инварианты, которые ломаются незаметно: неразрушающую запись
frontmatter, учёт занятых слотов, срабатывание гейтов. Красный тест — стоп
всему контуру до починки: автопилот с испорченной записью файлов за сутки
разложит весь корпус.

## Отчёт

Одним сообщением: пары на разведение, сироты, карантин, темп, статус тестов.
Если всё в норме — одна строка «неделя без отклонений», без подробностей.
