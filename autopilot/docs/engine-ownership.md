# Где живёт движок автопилота (ETK-P0-01)

Дата решения: 2026-09-21.

## Решение

**Авторитетная копия движка — `autopilot/` в репозитории TS_PIOT.**

Всё остальное — рабочие копии без права попадания в production.

| Путь | Роль | Может ли доехать до production |
|---|---|---|
| `TS_PIOT/autopilot/` | авторитетная production-копия | да — её запускает `.github/workflows/autopilot.yml` |
| `~/Documents/Etiketka` | песочница разработки движка | **нет** — у репозитория нет remote |
| `Etiketka/TS_PIOT-autopilot-runtime` | старый клон TS_PIOT | **нет** — ветка `wip/...`, уникальных коммитов нет |

## Почему именно так

Решение принято по фактам, а не по удобству:

1. **Только эта копия исполняется.** Production-workflow лежит в корневом
   `.github/workflows/` репозитория TS_PIOT и вызывает `autopilot/scripts/*.mjs`
   именно отсюда.
2. **У Etiketka нет remote.** Ни один коммит оттуда физически не может
   попасть в GitHub Actions. Песочница не может быть production-копией.
3. **Здесь есть защитные механизмы, которых нет в песочнице:**
   `scripts/lib/guard.mjs` (проверка `CONTENT_ROOT` до любой мутации, чтобы
   не писать в чужой сайт), `scripts/lib/site.mjs` (build-гейт принимающего
   проекта) и `scripts/migrate-reconcile.mjs` (миграция исторического
   состояния). Объявить авторитетной копию без них — снять эти проверки.

## Что это значит на практике

- Правка движка, сделанная в Etiketka, **не является выпущенной**. Чтобы она
  попала в production, её нужно перенести в `TS_PIOT/autopilot/` и провести
  через обычные тесты этого репозитория.
- Копии разошлись в обе стороны, поэтому слепая синхронизация каталогов
  запрещена: она удалит `guard.mjs`, `site.mjs` и `migrate-reconcile.mjs`.
  Переносить нужно пофайлово и осознанно.
- `autopilot/.github/` удалён. GitHub никогда его не исполнял, но он выглядел
  рабочим — из-за этой иллюзии ETK-P0-02 была независимо сделана дважды, в
  двух разных копиях. Отрицательная проверка на повторное появление такого
  каталога стоит в `scripts/workflow.test.mjs`.

## Что осталось незакрытым

Во вложенном клоне `Etiketka/TS_PIOT-autopilot-runtime` сохранена ветка
`wip/etk-p0-02-github-run-preserved` — незавершённый альтернативный вариант
ETK-P0-02 с `autopilot/scripts/github-run.mjs`: написание статей языковой
моделью прямо в CI (нужны `OPENROUTER_API_KEY` и `AUTOPILOT_MODEL`). Это
другой дизайн, чем детерминированный workflow в корне, он не проверялся и
не сливался. Решение о его судьбе — за владельцем.
