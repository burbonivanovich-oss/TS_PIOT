# Расписание автопилота

Автопилот работает без участия человека: раз в неделю обновляет темы и план,
каждый день пишет, проверяет и выпускает статьи, проверяет сайт и сообщает о
событиях. Владелец расписания один — `autopilot/scripts/scheduler.mjs` под
launchd на Mac владельца, в рабочей копии `TS_PIOT-autopilot-runner`.

## Что происходит

| Когда | Что | Где |
|---|---|---|
| Понедельник 04:00 UTC | Сбор спроса Wordstat, ротация запросов | GitHub Actions `wordstat-weekly.yml` |
| Первый запуск недели | Анализ рынка → темы и даты календаря; пополнение бэклога; план недели; коммит и push | `market.mjs`, `backlog.mjs week-plan` |
| Каждый день 09:00 (повтор 15:00, при входе в систему) | daily: факты, наряды, модель, гейты, сборка, коммит, push | `daily.mjs` |
| После push | Ожидание деплоя до 45 минут, проверка выпущенных страниц | `lib/live-release.mjs` |

Сделанный день повторно не запускается. Если Mac спал в 09:00, launchd
запустит задание при пробуждении. Выключенный Mac пропускает день, а
календарь выпуска потом догоняет пропуск в пределах 3 материалов в сутки.

## Анализ рынка

Модель (Claude Code CLI, только чтение и поиск в сети) получает
непокрытый спрос Wordstat и список уже существующих тем и предлагает до 12
тем и до 5 дат календаря. Код принимает тему, только если:

- каждый её ключ дословно совпадает со свежей фразой Wordstat;
- она не дублирует корпус, бэклог и `topicSeeds`;
- на одну сущность в неделю не больше трёх тем.

Дата календаря принимается только с прямой ссылкой на первоисточник из
списка `SOURCE_DOMAINS`. Принятое дописывается в `seeds.json` с пометкой
`source: "market"`; отказы и их причины — в `data/market-latest.json`. Сбой
модели не останавливает неделю: план строится из текущего бэклога.

## План недели

`data/week-plan.json`: NEW-темы на неделю — недельная доля месячной нормы
плюс две в запас, не больше трёх на сущность. Daily берёт темы сначала из
плана в его порядке, затем по обычному приоритету. План прошлой недели не
действует. Рерайты в плане — справка: их выбирает очередь рерайтов.

## Уведомления

Уведомление macOS приходит только о событии: вышли статьи (с заголовками),
построен план недели, выпуск не удался, сайт не обновился, нужна проверка
рабочей копии. Тихий день без выпуска уведомления не даёт.

Логи: `~/Library/Logs/etiketka-autopilot/` — `<дата>.log` планировщика и
`<дата>-daily.log` полного вывода daily. Состояние планировщика:
`~/Library/Application Support/etiketka-autopilot/state.json`, кратко —
`node autopilot/scripts/scheduler.mjs status`.

## Установка (один раз)

1. Токен Claude Code для работы без человека: `claude setup-token` (вход
   через браузер, подписка Claude), затем сохранить показанный токен в
   Связку ключей командой
   `security add-generic-password -U -s etiketka-autopilot-claude -a "$USER" -w`
   (токен вводится по запросу, в историю оболочки не попадает). Планировщик
   берёт его оттуда сам и не пишет в логи. Без токена выпуск готовых
   материалов идёт, а новые статьи и анализ рынка — нет; приходит уведомление.
2. Выключить в Codex автоматизацию «Этикетка — ежедневный выпуск». Если
   подписки Codex нет и выключить её нельзя — шаг пропустить и ставить с
   флагом `--codex-retired`.
3. Из корня runner: `node autopilot/scripts/install-scheduler.mjs install`
   (или `install --codex-retired`). Первый запуск начнётся сразу.
4. Если в `launchd.err.log` или логе дня есть «Operation not permitted»:
   Системные настройки → Конфиденциальность и безопасность → Полный доступ к
   диску → добавить `/usr/local/bin/node`. Под launchd доступ к `~/Documents`
   выдаётся главному процессу задания.

Удаление: `node autopilot/scripts/install-scheduler.mjs uninstall`.

## Когда планировщик останавливается

- **В рабочей копии незакоммиченные изменения или не та ветка.** Руками в
  runner не работать; разобрать изменения и вернуть чистую `main`.
- **Локальная история разошлась с remote** не из-за недельного коммита —
  daily восстанавливает свою доставку сам; иначе нужна проверка человеком.
- **Активна автоматизация Codex** — выключить её или, если подписки нет,
  переустановить с `--codex-retired`.
- **Claude не авторизован или упёрся в лимит подписки** — выпуск готовых
  идёт, новые тексты нет; уведомление называет причину. Токен обновляется
  повтором шага 1.
- **daily завершился ошибкой** — причина в `<дата>-daily.log`; повтор при
  следующем запуске. Красные тесты и стоп-условия daily (карантин больше 10,
  недостижимая норма) требуют человека.
